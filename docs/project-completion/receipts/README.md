# Receipts

Pro tatsächlich bearbeitetem Teilplan eine kurze Receipt nach `../contract.md`.
Durchführungen stehen in den einzelnen Receipts; `../state.md` benennt den
aktuellen Auftrag. Alte Evidenz nur gezielt referenzieren, nie als neuen Testlauf.
Auch unvollständige Versuche als `in-progress`/`blocked` speichern: letzte konkrete
Fehlersignatur, verworfene Ansätze, exakter nächster Check. Kein wachsendes Chatlog.
